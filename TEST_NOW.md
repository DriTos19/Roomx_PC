# ⚡ ULTRA-QUICK START - TEST IN 30 SECONDS

## The Fastest Way to Test

### Step 1: Add GameObject
1. In Hierarchy, right-click → Create Empty
2. Name it: "FBXImportTester"

### Step 2: Add Script
1. Select FBXImportTester GameObject
2. Drag `FBXImportTester.cs` to Inspector
3. Drag InventoryManager to the field

### Step 3: Test
1. Press Play ▶️
2. Press **I** in game
3. Type your FBX file path: `C:/path/to/model.fbx`
4. Press **Enter**
5. ✅ Done! Model imported!

---

## That's It! Now Test These Keys

| Key | Action |
|-----|--------|
| **I** | Open import dialog |
| **Enter** | Confirm path |
| **Escape** | Cancel |
| **F** | Quick test (edit path in code) |
| **D** | Import directory |
| **P** | List all items |
